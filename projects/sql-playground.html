What it shows

SQL skills, checked by the computer

The databases are the real outputs of my urban health access and health financing projects. Each challenge compares your result with a reference query, so it accepts any correct SQL, not one exact wording.

  • Aggregation and conditional averages.
  • A data-quality check that exposes double counting in the source data.
  • Window functions (RANK, LAG) over a country-year panel.
How it works

A database engine in a web page

SQLite is compiled to WebAssembly (sql.js), loads the 1.7 MB database file and runs every query locally. Nothing is sent to a server, so it is fast and private, and it is the same engine and SQL I used to build both projects.
