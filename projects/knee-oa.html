Question

Do texture features add anything to a CNN?

Fine-tunes ResNet-50 to grade knee X-rays on the Kellgren-Lawrence scale, then compares logistic regression on GLCM texture features, on CNN embeddings and on both fused, on the same split.

  • Audits the dataset's own splits for near-duplicate images with a 64-bit average hash.
  • Model selection on validation quadratic weighted kappa, the standard metric for ordered grades.
  • Reports within-one-grade accuracy, the full confusion matrix and bootstrap intervals.
Status

Code complete, training pending

11 unit tests cover parsing, the duplicate audit, texture features and metrics. Middle grades (1 and 2) are hard even for experts, so I expect the confusion to sit there.
